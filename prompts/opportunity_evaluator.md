# opportunity-evaluator-v1

Evaluate one normalized software engineering opportunity.

Output schema: `OpportunityEvaluation`

Return:

- executive summary
- fit score
- confidence score
- match analysis
- strengths
- concerns
- missing qualifications
- resume recommendations
- cover letter recommendations
- interview preparation topics
- suggested next action

Suggested next action must be one of:

- `prioritize`
- `review`
- `deprioritize`
